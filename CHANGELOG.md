# Changelog

All notable changes to whole-team. Versions follow semantic versioning.

## 0.1.0

First public release.

- `whole-team` skill: six rules, lifecycle router, ceremony profiles (lite, standard, strict), hats table, story loop.
- Reference guides: intake, scoping and pushback, right-sizing, board setup (GitHub Projects, Linear, Jira, Notion, local), requirements and stories, architecture, design, story loop, branching, sprint close, release, brownfield adoption, independent review.
- Templates for every document the profiles create, plus the working agreement block.
- `wt.py` helper (standard library only): `init`, `status`, `lint`, `lint --release`, `kanban`, `agreement`.
- Claude Code plugin: six slash commands and the `whole-team-reviewer` agent.
- Ten scenario evals, repository validator and CI.
