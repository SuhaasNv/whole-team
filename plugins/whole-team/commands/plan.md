Load the whole-team skill (it holds the rules, the reference files and the wt.py script), then follow reference/requirements-and-stories.md. Starting from SCOPE.md: personas, requirements with IDs, use cases grouped by epic (standard and strict), user stories in the exact format with testable acceptance criteria, story 000 as the walking skeleton if it does not exist, and a Definition of Ready and Done tailored to this project. Put stories not yet planned into a sprint as `Sprint: Backlog`. Run `wt.py lint`, fix every error, then mirror new or changed stories on the board (reference/board-setup.md). Finish by suggesting /whole-team:sprint to plan the next sprint.
