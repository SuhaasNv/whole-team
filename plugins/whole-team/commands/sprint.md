---
description: "Sprint planning: check last retro's actions, set a goal, pull ready stories within capacity, get the owner's yes"
argument-hint: "[sprint number, optional]"
---

Use the whole-team skill and follow the Sprint planning section of reference/sprints.md for sprint $ARGUMENTS (default: the next sprint). Check the last retrospective's actions, consider slipped stories first, propose a one-sentence goal, pull only stories that meet the Definition of Ready in dependency order within 70% of capacity, and write the exit criteria and cut order into SPRINTS.md. Show the plan to the owner and wait for a yes. On the yes: set each story's Sprint, set `sprint.current` in .whole-team.json, and mirror it on the board.
