# whole-team plugin

Controlled, agile development for one developer and their AI agent: scoping and pushback, use cases and stories, sprints with planning, review and retrospectives, a story loop with tests, docs and independent review, and release gates.

This folder is the installable plugin: the `whole-team` skill, 14 slash commands and the `whole-team-reviewer` agent. Full documentation, install options and examples: [github.com/SuhaasNv/whole-team](https://github.com/SuhaasNv/whole-team).

```
/plugin marketplace add SuhaasNv/whole-team
/plugin install whole-team@whole-team
```

Then run `/whole-team:help`.
